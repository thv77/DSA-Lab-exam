## Programs Included

| No. | Program | Main Concept |
|---|---|---|
| 1 | Student Marks | Selection Sort and Linear Search |
| 2 | Stack Using Linked List | Stack operations |
| 3 | DFS Using Adjacency Matrix | Depth First Search |
| 4 | DFS From Edges | Graph representation and DFS |

| 6 | Merge Linked Lists | Merging two singly linked lists |

## How to Compile and Run

You need a C compiler such as GCC.

1. Open a terminal in the repository folder.
2. Compile a program:

   ```bash
   gcc programs/1_student_marks.c -o student_marks
   ```

3. Run it:

   **Windows**
   ```bash
   .\student_marks.exe
   ```

   **Linux / macOS**
   ```bash
   ./student_marks
   ```

Replace the source filename and output name to compile another program.

## Purpose

This repository is intended for DSA lab practice and revision. The `programs/` folder contains the C source files, while the `pseudocodes/` folder contains the corresponding algorithm steps.
